# Privacy policy hosting

Public policy URL: https://gurkirat164.github.io/StreakGuard/Policies/

GitHub Pages publishes the `main` branch from the repository root. The policy
is served by `Policies/index.html`; `Policies/privacy-policy.html` contains the
same policy. Push policy updates to the published branch and verify deployment.

The app Settings link and Google Play Console declaration use the public URL
above. GitHub project sites inherit the account site's custom domain. The stale
`gurkirat.me` custom domain was removed from `Gurkirat164.github.io` because DNS
points to the Cloudflare portfolio, which otherwise receives policy requests.
Keep the GitHub account site on its default domain to preserve this policy URL.

Verify that the public URL stays on `gurkirat164.github.io` and displays the full
policy without signing in after every deployment. The Cloudflare Pages project
`streakguard-privacy` is an additional copy, not the canonical policy address.
